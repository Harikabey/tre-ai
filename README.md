# TreFriend - Akıllı Yapay Zeka Asistanı

TreFriend, Treasure şirketi tarafından geliştirilen gelişmiş yapay zeka sohbet asistanıdır.

## Özellikler

- 🧠 **Tam Hafıza Sistemi** - Tüm sohbetlerden öğrenir ve hatırlar
- 💭 **Gerçek Zamanlı Duygu Analizi** - Ruh halinizi anlayıp ona göre yanıt verir
- 🎯 **İlgi Alanı Haritası** - Kişiselleştirilmiş öneriler sunar
- 🎨 **Görsel Oluşturma** - AI ile görsel üretimi
- 🖼️ **Görsel Analizi** - Yüklenen görselleri analiz eder
- 📄 **Doküman Okuma** - PDF ve diğer dokümanları analiz eder
- 🎤 **Sesli Yanıt** - Mesajları sesli dinleyebilirsiniz
- 🗣️ **Sesli Giriş** - Mikrofonla mesaj gönderimi

## Teknolojiler

- React + TypeScript
- Tailwind CSS
- Shadcn UI
- Supabase (Veritabanı & Edge Functions)
- Google Gemini AI
- ElevenLabs TTS

## Kurulum

```sh
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev
```
