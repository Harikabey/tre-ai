# ⚡ Tre AI — Akıllı Yapay Zeka Asistanı

> **Treasure** tarafından geliştirilen **Tre**; kişiselleştirilmiş hafıza, gerçek zamanlı duygu analizi, canlı kamera/ekran işleme ve geniş dosya üretimi yeteneklerine sahip yeni nesil bir yapay zeka ekosistemidir.

---

### 🌟 Öne Çıkan Özellikler ve Modeller

* 🧠 **Kişisel Hafıza & Duygu Analizi:** Tüm sohbetlerden öğrenir, tercihlerinizi hatırlar ve ruh halinize göre tonda uyum sağlar.
* 🎭 **6 Farklı Kişilik & Düşünme Modları:** Arkadaş Canlısı, Profesyonel, Eğlenceli, Bilge, Yaratıcı ve Ayna modları; Hızlı ve Derin düşünme seçenekleri.
* 👁️‍🗨️ **Canlı Analiz & Multimodal Görüş:** 
  * Canlı kamera ve ekran paylaşımı analizi (kareler işlendikten sonra anında silinir).
  * Görsel/GIF üretimi, görsel, PDF ve video analizi.
  * 70+ formatta belge okuma, özetleme ve soru-cevap.
* 🎙️ **Sesli Etkileşim & Uyandırma Sözcüğü:** 
  * Yerel çalışan **"Hey Tre"** uyandırma sözcüğü ile eller serbest kullanım.
  * Tam ekran sesli mod ve ElevenLabs (TTS) entegrasyonu.
* 🛠️ **Dosya Üretimi & Dışa Aktarma:** 
  * APK, ISO, PPTX ve ses dosyası oluşturma.
  * Sohbet geçmişini istemci tarafında (lokal) PDF olarak dışa aktarma.
* 🌐 **Entegrasyon & Erişilebilirlik:** 
  * Google (Gmail/Drive) hesap bağlantıları ve web arama/kaynak gösterimi.
  * 114 dil desteği, web push bildirimleri ile hatırlatıcı kurma.
  * Yüksek kontrast, yazı ölçeği ve animasyon azaltma seçenekleri.


## Teknolojiler

- React + TypeScript
- Tailwind CSS
- Shadcn UI
- Supabase (Veritabanı & Edge Functions)
- Google Gemini AI
- ElevenLabs TTS

## Kurulum

```sh
# Bağımlılıkları yükle
npm install

# Geliştirme sunucusunu başlat
npm run dev
```
